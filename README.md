# Bancly

Aplicación web desarrollada con React y TypeScript enfocada en la gestión de dinero digital y operaciones bancarias básicas. Bancly ofrece una interfaz moderna, intuitiva y responsive, diseñada para brindar una experiencia rápida, limpia y fácil de usar.

## Características principales

* Inicio de sesión integrado
* Acceso rápido a funciones financieras
* Visualización de saldo disponible
* Transferencias de dinero
* Recargas
* Retiros
* Historial de movimientos
* Diseño moderno y adaptable

La aplicación incluye un sistema de autenticación, aunque actualmente permite iniciar sesión libremente para fines de demostración y pruebas del proyecto.

## Tecnologías utilizadas

* React
* TypeScript
* CSS
* Vite

## Objetivo del proyecto

Este proyecto fue desarrollado como práctica de desarrollo frontend utilizando React y TypeScript, enfocado en la creación de interfaces modernas, navegación entre componentes y diseño de experiencias digitales inspiradas en plataformas fintech.
